## 🚀 Anleitung: Auf GitHub hochladen

### Schritt 1: GitHub Repository erstellen
1. Gehen Sie zu [github.com](https://github.com) und loggen Sie sich ein
2. Klicken Sie auf **"New"** (grüner Button) oder **"+"** → **"New repository"**
3. Repository Name: `kk-gebaeudereinigung-website`
4. Wählen Sie **"Public"**
5. Klicken Sie auf **"Create repository"**

### Schritt 2: Dateien hochladen
1. Klicken Sie auf **"uploading an existing file"**
2. Ziehen Sie ALLE Dateien aus diesem Ordner in das Upload-Feld
3. Geben Sie eine Commit-Nachricht ein, z.B. "Website hinzugefügt"
4. Klicken Sie auf **"Commit changes"**

### Schritt 3: GitHub Pages aktivieren
1. Gehen Sie zu **"Settings"** (im Repository)
2. Scrollen Sie zu **"Pages"** (linke Seitenleiste)
3. Unter **"Source"** wählen Sie **"Deploy from a branch"**
4. Unter **"Branch"** wählen Sie **"main"** und **"/ (root)"**
5. Klicken Sie auf **"Save"**
6. Warten Sie 1-2 Minuten

### Schritt 4: Website aufrufen
Die Website ist nun live unter:
`https://[IHR-NUTZERNAME].github.io/kk-gebaeudereinigung-website`
